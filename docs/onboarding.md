# New engineer onboarding

## Day one
1. Read the README and architecture document.
2. Clone the repository and serve the documentation using the README command.
3. Read ADR-001 before suggesting a database change.
4. Review the open GitHub issues and choose a small task.

## Fictional responsibilities
- Morgan: product scope and MVP acceptance.
- Taylor: architecture and data storage.
- Casey: onboarding documentation and quality checks.

## Working agreements
Open a pull request for changes. Include the reason, user-visible effect, and verification performed. Do not commit secrets or real personal data.

## Common confusion
There is no runnable taskboard implementation yet. Port 8080 serves documentation only. No Docker, database server, or API token is required for this exercise.
